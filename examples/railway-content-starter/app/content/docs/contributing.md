# Contributing

Create a focused branch, keep each pull request about one documentation change,
and explain the audience and verification performed. Reviewers check technical
accuracy, links, navigation, public visibility, and whether examples avoid real
credentials or private data.

After merge, verify the resolved content commit and every reader, search,
catalog, and agent surface reached by the changed page.
