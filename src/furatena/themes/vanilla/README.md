# Vanilla layout

The immutable `vanilla` presentation pack is a complete, neutral layout for every built-in view
kind. It uses ordinary links and GET forms, emits no client scripts, and ships one small stylesheet
covering focus visibility, responsive reflow, reduced motion, and print/PDF output.

It consumes the same typed render contexts and framework metadata as the `docs` layout. It does
not alter Content IR, visibility, route, search, or agent contracts.
