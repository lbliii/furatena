# Docs layout

The immutable `docs` presentation pack contains Furatena's complete documentation shell and
all built-in view kinds. Its templates were extracted from the proven application layout and
continue to compose framework partials and Chirp UI components rather than duplicating routing,
visibility, search, or content policy.

Sites can shadow individual template names through `templates/`, `theme/`, or ordered v1 override
packs without modifying this package.
